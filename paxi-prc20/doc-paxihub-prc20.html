PRC-20 Token Tutorial

Complete guide to creating your own cryptocurrency token on Paxi Network using Android

What is PRC-20?

PRC-20 is a token standard on Paxi Network, similar to ERC-20 on Ethereum. It allows you to create your own cryptocurrency token with customizable features.

1

Create Token Script

Create a new JavaScript file for token creation:

nano create-token.js

Copy and paste the following code into the editor:

const { DirectSecp256k1HdWallet } = require("@cosmjs/proto-signing");
const { SigningCosmWasmClient } = require("@cosmjs/cosmwasm-stargate");
const { GasPrice } = require("@cosmjs/stargate");

async function createPRC20Token() {
  console.log("PRC-20 Token Generator");
  console.log("=".repeat(50));

  // CONFIGURATION - EDIT THIS SECTION
  const MNEMONIC = "your twelve word mnemonic phrase goes here";
  const TOKEN_NAME = "My Token";
  const TOKEN_SYMBOL = "MTK";
  const TOTAL_SUPPLY = 1000000;
  const DECIMALS = 6;
  const DESCRIPTION = "token on Paxi Network";
  const LOGO_URL = "";
  
  // Don't edit anything below!!!
  try {
    console.log("Token Configuration:");
    console.log("  Name: " + TOKEN_NAME);
    console.log("  Symbol: " + TOKEN_SYMBOL);
    console.log("  Supply: " + TOTAL_SUPPLY.toLocaleString() + " " + TOKEN_SYMBOL);

    console.log("\\nLoading wallet from mnemonic...");
    const wallet = await DirectSecp256k1HdWallet.fromMnemonic(MNEMONIC, {
      prefix: "paxi"
    });
    
    const [account] = await wallet.getAccounts();
    console.log("Wallet Address: " + account.address);

    console.log("\\nConnecting to Paxi Network...");
    const client = await SigningCosmWasmClient.connectWithSigner(
      "https://mainnet-rpc.paxinet.io",
      wallet,
      { gasPrice: GasPrice.fromString("0.05upaxi") }
    );

    const balance = await client.getBalance(account.address, "upaxi");
    const balancePaxi = parseFloat(balance.amount) / 1000000;
    console.log("Balance: " + balancePaxi.toFixed(6) + " PAXI");

    if (balancePaxi < 6) {
      console.log("\\nERROR: Insufficient balance!");
      return;
    }

    const totalSupplyWithDecimals = (TOTAL_SUPPLY * Math.pow(10, DECIMALS)).toString();
    const instantiateMsg = {
      name: TOKEN_NAME,
      symbol: TOKEN_SYMBOL,
      decimals: DECIMALS,
      initial_balances: [{
        address: account.address,
        amount: totalSupplyWithDecimals
      }],
      mint: { minter: account.address },
      marketing: {
        project: TOKEN_NAME + " Project",
        description: DESCRIPTION,
        marketing: account.address
      }
    };

    if (LOGO_URL) {
      instantiateMsg.marketing.logo = { url: LOGO_URL };
    }

    console.log("\\nCreating token on blockchain...");
    const result = await client.instantiate(
      account.address,
      1,
      instantiateMsg,
      TOKEN_NAME,
      "auto"
    );

    console.log("\\nTOKEN CREATED SUCCESSFULLY");
    console.log("Contract Address: " + result.contractAddress);
    console.log("TX Hash: " + result.transactionHash);
    console.log("Explorer: https://explorer.paxinet.io/paxi/tx/" + result.transactionHash);

    const fs = require('fs');
    fs.writeFileSync('token-info.json', JSON.stringify({
      tokenName: TOKEN_NAME,
      tokenSymbol: TOKEN_SYMBOL,
      contractAddress: result.contractAddress,
      transactionHash: result.transactionHash
    }, null, 2));

  } catch (error) {
    console.log("\\nERROR: " + error.message);
  }
}

createPRC20Token();

const { DirectSecp256k1HdWallet } = require("@cosmjs/proto-signing");
const { SigningCosmWasmClient } = require("@cosmjs/cosmwasm-stargate");
const { GasPrice } = require("@cosmjs/stargate");
const readline = require('readline');

const rl = readline.createInterface({
  input: process.stdin,
  output: process.stdout
});

function question(query) {
  return new Promise(resolve => rl.question(query, resolve));
}

async function main() {
  console.clear();
  console.log("🔧 PRC-20 TOKEN MANAGER");
  console.log("==================================================");
  console.log("\nSelect Action:");
  console.log("1. Add Liquidity");
  console.log("2. Renounce Minter Rights (Permanent)");
  console.log("3. Burn Tokens");
  console.log("4. Exit");
  
  const choice = await question("\nChoice (1-4): ");

  if (choice === '4') {
    console.log("Goodbye! 👋");
    rl.close();
    return;
  }

  const mnemonic = await question("Input Mnemonic: ");
  const tokenContract = await question("Token Contract Address: ");

  const wallet = await DirectSecp256k1HdWallet.fromMnemonic(mnemonic, {
    prefix: "paxi"
  });
  const [account] = await wallet.getAccounts();

  const client = await SigningCosmWasmClient.connectWithSigner(
    "https://mainnet-rpc.paxinet.io",
    wallet,
    { gasPrice: GasPrice.fromString("0.05upaxi") }
  );

  try {
    if (choice === '1') {
      const paxiAmount = await question("PAXI Amount: ");
      const tokenAmount = await question("Token Amount: ");
      console.log("\n💧 Adding liquidity...");
      // Implementation logic goes here
      
    } else if (choice === '2') {
      console.log("\n🚫 Renouncing minter rights...");
      const msg = { update_minter: { new_minter: null } };
      const result = await client.execute(account.address, tokenContract, msg, "auto");
      console.log(`✅ Success! TX: ${result.transactionHash}`);
      
    } else if (choice === '3') {
      const burnAmount = await question("Burn Amount: ");
      console.log("\n🔥 Burning tokens...");
      const msg = { burn: { amount: (burnAmount * 1000000).toString() } };
      const result = await client.execute(account.address, tokenContract, msg, "auto");
      console.log(`✅ Success! TX: ${result.transactionHash}`);
    }
  } catch (error) {
    console.log("\n❌ ERROR:", error.message);
  }

  rl.close();
}

main();

Frequently Asked Questions

How much does it cost to create a token?

Token creation costs approximately 6 PAXI for gas fees. Additional operations cost around 0.02-0.05 PAXI each.

Can I edit my token after creation?

You can update the logo and description. However, you cannot change the token name, symbol, decimals, or total supply.

What happens if I close Termux?

All your files remain saved. Simply reopen the app and navigate to your project folder:

cd token-generator

How do I backup my token information?

Install termux-api and setup storage access:

pkg install termux-api
termux-setup-storage
cp token-info.json ~/storage/downloads/

Is renouncing minting rights reversible?

No. This is permanent and cannot be undone. After renouncing, no one can ever mint new tokens.

How do I check my token on the blockchain?

Visit the Paxi Network explorer:

Open Paxi Explorer

Can I create multiple tokens?

Yes. You can create as many tokens as you want. Simply edit the configuration and run the script again.

What if I get an error during creation?

Common errors and solutions:

  • Insufficient balance - Add more PAXI to your wallet
  • Invalid mnemonic - Check your 12-word phrase
  • Connection error - Verify internet connection
  • Contract error - Ensure all parameters are valid
